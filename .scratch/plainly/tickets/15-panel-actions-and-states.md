# 15: 面板的动作与完整状态

**What to build:** 面板长成一个能长期用的表面——看得到这条解释出自谁、能复制、能一键换云端重生成、能跳去历史；位置与自动消失按我的偏好；长输入和两种拒绝也都有交代与出路。

**Blocked by:** 11, 13, 14

**Spec:** [spec.md](../spec.md) §12 面板（外观、退出路径、多块与拒绝态）

**Status:** ready-for-agent

- [ ] 标题栏：provenance chip（云 / 本地可区分）+ 复制 / **⟳ 重新生成**（绕开缓存）/ ⤢ 打开主窗口（single-instance 交接）/ ✕
- [ ] 分节可折叠；Grammar 为空时显示「本段不需要」而不是消失；Gloss 保序
- [ ] 本地 provider 时正文下方**固定**一条核对提示（对照上方原文，或 ⟳ 换成云端重新生成）
- [ ] 自动消失是两个**独立**键（开关默认关；打开后默认 20 秒），不用时长 `0` 表示「永不」
- [ ] 位置是四角 + 跟随当前显示器（分辨率无关，换显示器不会把面板丢到屏幕外）；不做自由拖动
- [ ] 多块输入按原文顺序**堆叠**在一个可滚动面板里（不做分页，没有隐藏状态）
- [ ] 「内容被标记为敏感」与「输入过长（> 5 块）」两种拒绝态明说原因，且**同样有出路**，不会被关不掉
- [ ] 界面文案是中文且集中在一份可替换资源里（不引 i18n 框架）；加载 / 结果 / 出错 / 拒绝四种状态都能关掉
- [ ] 面板宽约 470px、不抢焦点，`activate` 复用语义不变
