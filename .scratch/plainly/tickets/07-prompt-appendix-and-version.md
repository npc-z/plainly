# 07: 提示词：附录、内容哈希与迁移

**What to build:** 出厂提示词随版本更新、我追加的规则不丢；版本号不再靠人自觉——改了任何一个字版本就变，旧答案不会被误命中，而旧记录也不会被偷偷改写。

**Blocked by:** 03

**Spec:** [spec.md](../spec.md) §5 提示词模型

**Status:** ready-for-agent

- [ ] 有效提示词 = 出厂默认（不可变、随应用更新）+ 用户附录；附录**只能追加**，界面与文档说清原因
- [ ] 出厂默认是**内联等级描述表**的版本：`{{LEVEL}}` 代入「标签 + 含义」；C1 的描述不与「必须是真改写」冲突
- [ ] `prompt_version` = `SHA-256(出厂默认 + 用户附录 + 等级描述表)`，占位符不参与替换；改一句描述会改变哈希（有测试）
- [ ] Record 同时携带哈希与人类可读标签；**不存提示词正文**，旧记录永远可渲染
- [ ] 契约持续失败时给出「你的提示词没通过契约」与一键「改用出厂默认重试」，并记录真正产出它的那个提示词
- [ ] 改 Level / 母语不触碰任何旧 Record：同一段落在新等级下是**新查询**（新 key → 新记录）
- [ ] 输出小节开关是显示层开关：不改提示词、不改 schema、不进 Lookup Key，切换即时且不必重新生成
