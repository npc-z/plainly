# 14: 主窗口

**What to build:** 按 ⤢ 进入的那个世界——左边历史和搜索、右边详情、设置能改所有选项；第一次打开时它直接把我带到还缺的那一步。

**Blocked by:** 07, 09, 10, 12

**Spec:** [spec.md](../spec.md) §13 主窗口

**Status:** ready-for-agent

- [ ] Tauri 窗口：顶部标签（历史 / 设置）+ 左侧常驻列表（约 330px，含搜索框）+ 右侧详情；列表按日期分组（今天 / 昨天 / 更早）
- [ ] 搜索只搜英文字段，搜索框下有一行「中文翻译暂不可搜」；标签在详情里编辑、在列表里作为可点击的筛选 chip
- [ ] 列表行显示提示词版本（连同 provider / 模型 / 等级 / 标签 / 时间），同一段落的多版本不被当成重复条目
- [ ] 导出两处分工：详情里「复制 markdown / 导出这一条」，设置的数据节里三条全局导出
- [ ] 设置五节（语言与等级 / Provider / 提示词 / 行为 / 数据）：等级**带含义**显示；提示词附录编辑器并解释「只能加不能删」；思考开关默认关；「复制自动弹」能力不足时灰掉 + 可操作说明
- [ ] 首次运行（没有 key / 没有可用 provider）直接开在设置页的空状态，**不做**独立引导流
- [ ] 面板位置与自动消失的控件就位（开关默认关、时长默认 20 秒且仅在开关打开时可用），写入 `[app]`
