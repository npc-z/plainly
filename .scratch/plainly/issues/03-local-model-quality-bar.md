# 03 默认本地模型质量门槛

Type: task
Status: open

## Question

用真实样本定出**本地模式的质量门槛与默认模型**——调研明确指出这是公开资料里没有答案的唯一问题，只能自己测。

在 llama.cpp 上（本机已装 `llama-server`，无 CUDA、16GB 内存）对同一份 **~100 段难英语**样本跑 A/B：

- 候选：Qwen3.5-9B、Gemma 4 12B、gpt-oss:20b（内存允许的话再加一档）。
- 条件统一：同一份 schema 约束解码、temperature 0、`-c` 给足上下文（绕开 Ollama 那个 `num_ctx` 无法经 OpenAI 兼容 API 设置的坑）。
- 评分维度：**契约遵循率**（schema 校验通过率，这是主要指标）、gloss 质量、改写是否保留有用的难度、翻译质量、单次耗时。

产出：默认模型 + 最低硬件建议 + **本地模式对外怎么描述**（诚实版：16GB 是"可用但降级"，不是云端平替）。
